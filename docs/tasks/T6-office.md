# T6 — 오피스 실데이터화

- 상태: 대기 · 브랜치: `feature-office-db` · 의존: T4(usage_events)·T2(admin) · 커밋 계획: 2개 — 유저·제재 / 대시보드 합산
- 설계 근거: [server-design.md](../server-design.md) §5(화면 전환)·§6(실사용 지표), 확인 포인트 B·C

## 목표

유저 관리가 실제 가입 유저를 다루고 제재가 효력을 가진다. 대시보드·비용의 활동 지표에
실사용(usage_events·실가입)이 시드 지표와 합산되어 나타난다.

## 범위

- **포함**: 유저 목록·상세 SQL 전환, 제재 API·세션 무효화, 대시보드·비용 합산, 실험 페이지 DB 조회
- **제외**: 매출·GPU 비용·마진·모델별 차트의 실데이터화(시드 전용 유지 — 확인 포인트 C), 차트 킷 변경(불필요)

## 작업 항목

### 유저 관리·제재 (커밋 1)

- [ ] 유저 목록 — RSC + SQL: 검색(닉네임/이메일 ilike), 플랜·상태 필터, 정렬(last_active_at/turns/토큰), 20명 페이징(offset). searchParams 기반으로 전환해 URL 공유 가능해짐. 시드 800 + 실가입 유저 한 목록(실가입 표시 배지)
- [ ] 유저 상세 — DB 조회. 턴·토큰은 시드값(users 행) + usage_events 합산으로 표시
- [ ] `POST /api/admin/users/[id]/sanction` — status 토글 + 해당 유저 sessions 전체 삭제(즉시 로그아웃). SanctionControls를 API 연결로 교체, "데모: 이 세션에서만 반영돼요" 문구 제거

### 대시보드·비용 합산 (커밋 2)

- [ ] 합산 쿼리 — 선택 구간(7/30/90일)을 날짜별로: `daily_metrics`(시드, ~08-31) + 실데이터(그 이후). 실데이터 = usage_events 일별 집계(턴=행 수, DAU=distinct user, 토큰=추정 합) + users 실가입(신규)
- [ ] 대시보드 — KPI·DAU 추이·기간 비교가 합산 시계열 기준으로 동작(기존 metrics-utils 입력 형태에 맞춰 변환하면 차트는 무변경)
- [ ] 비용 — 처리 토큰 KPI·주간 토큰 스택에 실사용 토큰 반영("추정치 포함" 라벨 — 확인 포인트 B). GPU 비용·마진·원가표는 시드 전용 유지 + "시드 데이터" 캡션
- [ ] 실험 페이지 — mocks 직접 import를 DB 시드 조회로 교체(읽기 전용)

## 테스트

- [ ] 유닛 — **시드+실사용 합산 함수**: 겹치지 않는 날짜 이어붙이기, 겹치는 날 더하기, 실데이터 없는 구간(순수 시드), 시드 없는 미래 날짜(순수 실데이터), 기간 경계(7/30/90) / 기존 이관분: office `format`(만/억·₩·%·delta null)·`niceTicks`·주간 묶음(자투리 버림)
- [ ] 통합(docker DB) — 유저 목록 쿼리: 검색(ilike)·플랜/상태 필터·정렬 3종·페이징(경계·범위 밖 clamp)·시드+실가입 혼재 / **제재**: status 변경 + 해당 유저 sessions 전부 삭제 → login 거부·/api/chat 403, 해제 시 복구 / usage_events 집계(일별 distinct user·턴·토큰 합)
- [ ] E2E 시나리오 추가 — 웹에서 모의 채팅 수 턴 → 오피스 대시보드(7일)에서 오늘 턴·DAU 반영 확인 → 유저 검색 → 제재 → 그 계정 로그인 차단 → 해제

## 구현 노트

- 시드 daily_metrics는 08-31에 끝나고 실사용은 09-01부터 쌓이므로 **날짜 겹침이 없다** — 합산은
  사실상 시계열 이어붙이기. 겹치는 날이 생겨도 더하기로 정의(주석 명시).
- 기간 필터의 "기준일"이 시드 TODAY(08-31)에서 **실제 오늘**로 바뀐다 — 화면 헤더의 기준일 표기도 갱신.
- 유저 목록이 서버 페이징으로 바뀌므로 기존 클라이언트 필터 state는 searchParams로 이관(칩·select UI는 유지).
- 800명 시드 유저의 country·tokensByModel 등 기존 표시 항목은 시드 컬럼에서 그대로.

## 완료 기준

- 실가입 유저가 목록·상세에 보이고 검색·필터·정렬·페이징이 시드+실가입 통합 목록에서 동작
- 제재 → 해당 유저 즉시 로그아웃 + 로그인 차단("제재된 계정이에요") + /api/chat 403, 오피스 새로고침에도 유지, 해제 시 복구
- 웹에서 모의 채팅 몇 턴 → 오피스 대시보드의 오늘 날짜 턴·DAU·토큰에 반영, 신규 가입도 반영
- 비용 페이지의 시드 전용 차트에 캡션 표시, 기존 차트 인터랙션(크로스헤어·표 전환) 무변경
