## 3. 유저 앱(web) 스펙 — 구현 완료

모바일 퍼스트. 공통 셸은 상단 Header(로고·데스크톱 네비·아바타/로그인) + 모바일 하단
TabBar(홈/대화/만들기/MY). 채팅방과 로그인만 셸 없는 전체화면.

| 라우트 | 페이지 | 렌더링 |
| --- | --- | --- |
| `/login` | 데모 로그인 | 클라이언트 |
| `/` | 홈 피드 | 클라이언트 |
| `/plots/[id]` | 플롯 프로필 | 정적 12개 프리렌더 + 유저 플롯 클라이언트 해석 |
| `/chat` | 대화 목록 | 클라이언트 |
| `/chat/[id]` | 채팅방 (전체화면) | 정적 프리렌더 + 클라이언트 |
| `/create` | 만들기 위저드 | 클라이언트 |
| `/my` · `/my/ai` · `/my/plots` | MY · AI 연결 · 내 플롯 | 클라이언트 |
| `/notices` · `/notices/[id]` | 공지 목록·상세 | 서버(정적, 전체 프리렌더) |

### 로그인 `/login`
- **구성** — θ 로고 → 환영 문구 → 데모 계정 카드 3개(신규 무료 유저 / 헤비 세타패스 유저 / 크리에이터, PASS 배지) → "로그인 없이 둘러보기" 링크.
- **기능** — 카드 클릭 시 세션 저장 후 홈으로 이동. 비밀번호·OAuth 없음(실서비스라면 OAuth 자리).
- **상태** — 이미 로그인된 상태로 방문해도 선택 화면 그대로 노출(§7 갭 ②).

### 홈 피드 `/`
- **구성** — 고정 공지 배너(pinned 1건) → 태그 필터 칩(전체 + 10개, 가로 스크롤) → 플롯 카드 그리드(2→3→4열).
- **카드** — 4:3 그라디언트+이모지 커버(외부 이미지 없음), 내 플롯 "MY" 배지, 이름·한 줄 소개·태그 2개·💬/❤️ 수(만 단위 축약).
- **기능** — 태그 단일 선택 토글 필터. 정렬은 내 플롯 우선 + 대화수 내림차순.
- **상태** — 필터 0건 빈 문구. 로그인 없이 전부 열람 가능(의도).

### 플롯 프로필 `/plots/[id]`
- **구성** — 그라디언트 커버 헤더(이름·"내 플롯" 배지·@크리에이터·💬❤️·태그 전체) → 소개 → 첫 메시지 원문 → 하단 sticky CTA "OO와/과 대화 시작하기"(조사 자동 선택).
- **상태** — 유저 플롯은 복원 전 스피너, 못 찾으면 전용 NotFound("삭제됐거나 다른 브라우저에서 만든 플롯"). 정적 플롯은 즉시 렌더.

### 채팅방 `/chat/[id]` — 핵심 화면
- **구성** — 전체화면 3단: 헤더(뒤로·아바타·이름·현재 모델 배지→AI 설정 링크·대화 초기화) / 메시지 영역 / 자동 높이 Composer.
- **롤플레잉 렌더링** — `*별표*` 구간은 행동 지문(기울임·흐림), 나머지는 대사. 스트리밍 중 안 닫힌 별표도 지문으로 처리.
- **전송** — Enter 전송(IME 조합 보호), Shift+Enter 줄바꿈. 첫 토큰 전 타이핑 인디케이터.
- **제어** — 중단(받은 부분 보존 + "응답이 중단됐어요" 표시) · 마지막 응답 다시 생성 · 마지막 유저 메시지 인라인 수정/다시 보내기(그 지점부터 대화 잘라내고 재요청) · 대화 초기화(confirm, 첫 메시지만 남김) · 에러 시 재시도.
- **스크롤** — 하단 80px 이내에 있을 때만 자동 스크롤(위로 읽는 중엔 방해 안 함).
- **상태** — 방 없으면 첫 메시지로 자동 개설. BYOK 설정 누락은 서버 왕복 전에 검증해 "AI 설정" 링크와 함께 안내. 언마운트 시 진행 중 스트림 abort.

### 대화 목록 `/chat`
- **구성** — 방 카드 목록: 아바타·이름·마지막 메시지 미리보기(지문 별표 제거, 48자)·상대 시간(방금/n분/n시간/어제/M월 D일). 최근 갱신순.
- **상태** — 복원 전 스피너, 빈 상태는 "캐릭터 찾아보기" 버튼. 삭제된 플롯의 방은 목록에서 제외.

### 만들기 위저드 `/create` — 4단계
- **공통** — 진행 바(1.프로필 → 2.페르소나 → 3.첫 메시지 → 4.공개 설정), 이전/다음, 단계별 검증 에러 배너(입력 수정 시 즉시 해제). 로그인 필수(비로그인은 안내+로그인 버튼).
- **1 프로필** — 이름(20자)·한 줄 소개(40자)·커버 이모지 24종·그라디언트 12종.
- **2 페르소나** — 세계관 소개(300자, 공개)·성격/말투(500자, 비공개 — "AI가 연기할 설정" 안내).
- **3 첫 메시지** — 500자, `*지문*` 문법 안내, 실제 채팅 말풍선과 동일한 파서로 실시간 미리보기.
- **4 공개 설정** — 태그 최대 4개(추천 20종 + 직접 입력, #·공백 제거·8자 컷, IME 보호) · 공개/비공개 선택 · 실제 PlotCard 미리보기.
- **제출** — `u-` 접두 id로 생성(creator=닉네임, 대화/좋아요 0) → 프로필로 이동. 이후 홈·채팅·목록에서 기본 플롯과 동일하게 동작.
- **상태** — 초안은 페이지 이탈 시 소실(자동 저장 없음, §7 갭 ③).

### MY `/my` · 내 플롯 `/my/plots`
- **MY** — 프로필 카드(플랜 배지) + 메뉴 3개(공지·내 AI 연결·내가 만든 플롯) + 로그아웃. 비로그인은 로그인 안내.
- **내 플롯** — 행마다 프로필 링크·"대화" 버튼·"삭제". 삭제는 confirm 후 플롯과 해당 대화방을 함께 정리. 빈 상태는 "첫 플롯 만들기". 수정 기능은 없음(§7 갭 ④).

### 내 AI 연결 `/my/ai` — BYOK 설정
- **구성** — 모드 2택(데모 모델 / 내 AI 연결) → BYOK일 때만 프로바이더·엔드포인트·API 키(password)·모델 입력 → 연결 테스트 → "키는 이 브라우저에만 저장" 고지.
- **프리셋 5종** — OpenAI / OpenRouter / Ollama(로컬, 키 불필요) / OpenAI 호환 직접 입력 / Anthropic. 프리셋 선택 시 엔드포인트 자동 입력, 키 불필요 프리셋은 라벨이 "(선택)"으로.
- **기능** — 모든 입력 즉시 자동 저장(저장 버튼 없음). 연결 테스트는 실제 스트림을 열어 40자 수신 후 중단, 성공 시 응답 예시 표시, 실패 시 업스트림 에러 그대로 노출.

### 공지 `/notices` · `/notices/[id]`
- **구성** — 목록(카테고리 배지·고정 표시·제목·날짜, 5건) / 상세(제목·날짜·본문 줄바꿈 보존). 전부 정적 프리렌더, 없는 id는 404.

### 클라이언트 상태 계층 (zustand persist → localStorage)

| 스토어 (storage key) | 저장 내용 | 주요 액션 |
| --- | --- | --- |
| `theta-session` | 로그인 유저(id·닉네임·플랜·hue) | login / logout |
| `theta-chats` | 플롯별 대화방(메시지·중단 플래그·갱신 시각) | 방 개설(idempotent)·추가·마지막 응답 제거(첫 메시지 보호)·특정 지점부터 잘라내기·초기화 |
| `theta-my-plots` | 내가 만든 플롯 전체 | 추가(맨 앞)·삭제 |
| `theta-ai-settings` | 모드(mock/byok)·프리셋·엔드포인트·API 키·모델 | 프리셋 적용·부분 수정·요청 전 누락 검증 |

loading / ready / missing을 확정한다 — 프로필·채팅방의 스피너와 NotFound 분기가 전부 여기서 나온다.

## 4. 백엔드 스펙 — 구현 완료

BYOK 구조라 백엔드는 스트리밍 프록시 하나다. 키를 서버에 저장하지 않는 것이 설계의 핵심이고,
그 외 데이터는 전부 정적 프리렌더와 mocks 패키지가 담당한다.

### POST `/api/chat` — 채팅 스트리밍 프록시 (Node 런타임)

- **요청** — `{ provider: {kind, baseUrl?, apiKey?, model?}, system, plotName, messages[] }`. 키는 localStorage에서 요청 본문에 실려 올 뿐 서버에 남지 않음.
- **입력 정리** — 최근 40턴만 유지, 메시지당 8,000자 컷, role이 user/assistant가 아니면 400. 시스템 프롬프트는 클라이언트(`lib/ai/prompt`)가 플롯 페르소나로 조립.
- **프로바이더 3종**
  - `mock` — 서버가 조사(을/를·이/가) 처리된 롤플레잉 응답을 생성해 600ms~1.1s "생각" 지연 후 1~3자씩 지연 스트리밍(첫 대화는 인사말).
  - `openai` — OpenAI 호환 `{baseUrl}/chat/completions` (Bearer, OpenAI·OpenRouter·Ollama 겸용).
  - `anthropic` — `/v1/messages` (x-api-key, max_tokens 1024).
- **스트림 변환** — 업스트림 SSE를 서버에서 파싱해(`sseToTextStream`: 청크 경계 버퍼링, `[DONE]`·불완전 JSON 라인 스킵) 순수 텍스트 청크 스트림으로 변환. 응답 헤더는 `text/plain · no-store · x-accel-buffering: no`. 클라이언트는 SSE를 몰라도 됨.
- **타임아웃** — 업스트림 연결(응답 헤더 도착)까지만 20초 제한, 스트리밍 본문은 무제한. 클라이언트 abort는 업스트림까지 전파.
- **에러** — 400 잘못된 형식 / 499 클라이언트 중단 / 502 업스트림 실패(한국어 안내로 변환: 키 미입력·모델 미입력·연결 지연·연결 실패 각각 구분, 업스트림의 에러 메시지는 노출).

백엔드가 이게 전부인 이유: 인증(데모 계정)·대화 기록·유저 플롯은 전부 브라우저 저장이고,
공지·플롯·오피스 지표는 시드 고정 mocks다. 실서비스라면 이 자리에 DB·인증·공지 API가 붙는다는
점을 README에 명시할 예정.

## 5. 오피스(office) 스펙 — 구현 완료

좌측 고정 사이드바(모바일에서 아이콘 레일) + 5개 메뉴. 차트는 라이브러리 없이 자체 SVG 킷으로
그렸고, 모든 차트는 표 전환을 갖춰 접근성 경로를 보장한다.

### 대시보드 `/`
- **구성** — 기간 칩(7/30/90일, 기본 30일) → KPI 타일 4개(평균 DAU·신규 가입·대화 턴·구독 매출 — 각각 스파크라인 + 직전 동일 구간 대비 증감) → 차트 2개: DAU 추이(단일 시리즈, 영역 워시+끝값 라벨) / 매출·비용(구독 매출·GPU 비용·결제 수수료 3시리즈).
- **기능** — 기간 전환 시 KPI·차트 전부 재계산. 90일 선택 시 비교 구간이 없어 증감 표시는 자동 생략.

### 비용·모델 `/cost`
- **구성** — KPI 4개(GPU 서빙 비용 — 증가가 나쁨이라 상승을 위험색으로 · 처리 토큰 · 유저·일당 서빙 비용 · 공헌 마진율 = (매출−수수료−GPU)/매출) → 주간 모델별 토큰 스택 바 → 모델별 일간 GPU 비용 라인 → 모델 원가표(1M 토큰당 입·출력 단가 + 선택 구간 토큰 비중).
- **규칙** — 모델 색 고정 매핑(koji-lite 파랑 / koji 주황 / luca 청록)이라 어떤 차트·표에서도 같은 모델은 같은 색.

### 유저 관리 `/users` · `/users/[id]`
- **목록** — 800명. 검색(닉네임/ID 부분일치) + 플랜·상태 필터 + 정렬(최근 활동/턴/토큰) + 20명 페이징. 필터 변경 시 1페이지로 리셋, 행 클릭 시 상세.
- **상세** — 프로필(플랜·국가·가입/활동) → 스탯 3개(누적 턴·누적 토큰·턴당 토큰) → 모델별 토큰 100% 스택 바 + 추정 서빙 원가 → 즐겨찾는 플롯. 없는 id는 404.
- **제재** — confirm 후 제재/해제 토글. "데모: 이 세션에서만 반영" 명시(새로고침 시 원복).

### A/B 실험 `/experiments` · 공지 관리 `/notices`
- **실험** — 진행 중 2건·종료 1건. 카드마다 가설 → D1 리텐션·유저당 턴 A/B 가로 막대 비교(실험군 강조색·대조군 회색, 값 직접 라벨) → 변형별 참여자 수 + 리프트 요약 → 결론 박스.
- **공지 관리** — 작성 폼(카테고리·제목 60자·본문 1,000자, 빈 값이면 게시 비활성) + 목록(고정 토글·confirm 삭제). 새 공지는 오늘 날짜로 맨 앞에 추가. 로컬 상태라 새로고침 시 시드 5건으로 복원 — "실서비스라면 API로 유저 앱에 반영"을 화면에 명시.

### 차트 킷 `components/charts` — 자체 SVG, 라이브러리 없음
- **LineChart** — 멀티 시리즈, ResizeObserver 실측 폭, 1/2/2.5/5 스텝의 y축 눈금(0 시작), 포인터 스냅 크로스헤어 + 전 시리즈 툴팁, ←/→ 키보드 탐색·Esc 해제, 시리즈 2개 이상이면 범례.
- **StackedBarChart** — 주간 스택, 세그먼트 2px 갭·최상단만 라운드, 슬롯 전체가 히트 영역, 툴팁에 합계 행, 키보드 지원.
- **StatTile / Sparkline** — KPI 값 + ▲▼ 아이콘 병기(색에만 의존하지 않음), `upIsGood`으로 증가=나쁨 지표 반전, 96×28 미니 추세선은 끝점만 강조.
- **ChartCard + SeriesTable** — 모든 차트에 "표 보기" 전환 필수(sticky 헤더·tabular-nums). 툴팁 없이도 모든 값에 도달 가능.
- **팔레트** — dataviz 검증 통과 5색(순서 고정 = 색약 안전장치), 한 차트 최대 3시리즈, 강조 바이올렛·비강조 회색 별도, 상태색은 시리즈색과 미혼용.

## 7. 알려진 한계와 발견된 갭

앞 두 개는 의도된 데모 한계, 뒤 네 개는 이번 스펙 점검(09-01)에서 새로 발견한 갭.

- **공지 오피스↔웹 미연동** — 오피스(:3001)의 작성·고정·삭제는 로컬 상태라 웹(:3000)에 반영되지 않음(오리진 분리로 localStorage 공유 불가). 화면에 명시된 의도된 한계. → 질문 ④
- **배포 없음** — 로컬 실행 기준. BYOK라 서버 비밀이 없어 Vercel 배포 부담은 낮음. → 질문 ②
- **갭 ① 비공개 설정 미반영** — 만들기 4단계에서 "비공개"를 골라도 값이 저장되지 않아 홈 피드에 그대로 노출된다. 사실상 버그로 판단, 수정 추천(반나절 이하). → 질문 ⑥
- **갭 ② 로그인 페이지 재방문** — 이미 로그인된 상태에서 /login 접근 시 리다이렉트 없이 선택 화면이 다시 보임.
- **갭 ③ 만들기 초안 소실** — 위저드 도중 이탈하면 작성 내용이 사라짐(자동 저장 없음).
- **갭 ④ 플롯 수정 불가** — 만든 플롯은 삭제만 가능하고 수정 화면이 없음(위저드 재활용으로 가능하나 반나절+ 소요).
