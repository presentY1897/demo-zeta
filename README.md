# Theta (θ) — AI 인터랙티브 스토리 플랫폼

AI 캐릭터와 대화하며 이야기를 만들어가는 서비스와, 그 서비스를 운영하는 오피스를 한 저장소에 담았습니다.
[제타(zeta-ai.io)](https://zeta-ai.io)를 오마주한 포트폴리오 프로젝트입니다.

### 이 두 개를 이어서 보시면 좋습니다

1. 유저 앱에서 **아무 캐릭터와 몇 마디 나눠 보세요.** API 키 없이도 모의 모델이 스트리밍으로 답합니다.
   중간에 **중단**을 눌러 보시고, 새로고침해 보세요 — 받은 데까지가 그대로 남아 있습니다.
2. 오피스 **대시보드**를 열면 방금 그 대화가 오늘 날짜의 턴·DAU에 **합산**돼 있습니다.
3. 오피스 **공지 관리**에서 공지를 하나 쓰고 고정한 뒤, 유저 앱 홈을 새로고침해 보세요 — 배너가 바뀝니다.
4. 오피스 **유저**에서 방금 가입한 계정을 제재해 보세요. 그 계정은 즉시 로그아웃되고 로그인이 막힙니다.

## 무엇을 만들었나

### 유저 앱 (`apps/web`) — 모바일 퍼스트

- **홈 피드** — 큐레이션 플롯 12개 + 유저가 만든 공개 플롯. 태그 필터는 URL에 실려 공유됩니다.
- **채팅** — 스트리밍 렌더링, 중단(부분 보존), 다시 생성, 마지막 메시지 수정 후 다시 보내기, 초기화.
  `*별표*` 구간을 행동 지문으로 렌더링합니다.
- **만들기** — 4단계 위저드(프로필 → 페르소나 → 첫 메시지 → 공개 설정). 커버 이미지를 올리면
  브라우저에서 4:3 크롭·리사이즈·webp 재인코딩 후 업로드하고, 안 올리면 이모지+그라디언트가 폴백입니다.
- **내 AI 연결(BYOK)** — OpenAI 호환 / Anthropic / 로컬 Ollama. **키는 브라우저에만 저장**되고
  서버에는 남지 않습니다. 키가 없으면 모의 모델로 전 기능이 동작합니다.
- 이메일 회원가입 + Google 로그인, 공지사항.

### 운영 오피스 (`apps/office`)

- **대시보드** — 기간별 KPI와 추이. 시드 지표(90일)에 **실사용을 합산**해 보여줍니다.
- **비용·모델** — 모델별 토큰·GPU 비용·공헌 마진. 차트는 **라이브러리 없이 직접 그린 SVG**이고
  전부 "표 보기"로 전환됩니다.
- **유저** — 시드 800명 + 실가입 유저를 한 목록에서. 검색·필터·정렬·페이징이 전부 SQL이고 URL에 실립니다.
  제재하면 **실제로** 세션이 끊기고 로그인·대화가 막힙니다.
- **A/B 실험**, **공지 관리**(작성·고정·삭제가 유저 앱에 즉시 반영).

## 기술 선택과 그 이유

스택은 pnpm + Turborepo 모노레포, Next.js 15 App Router, React 19, Tailwind v4,
Postgres + Drizzle, Vercel + Neon입니다. 그보다 **왜 그렇게 했는지**를 적습니다.

### BYOK — API 키를 서버에 두지 않는다

AI 응답은 유저가 등록한 자기 키로 나갑니다. 키는 브라우저 `localStorage`에만 저장되고,
대화 요청마다 본문에 실려 **서버를 통과만** 합니다. 서버는 저장하지도, 로그에 남기지도 않습니다.

- 데모를 공개하면서 제 키를 태우지 않아도 되고, 리뷰어는 자기 키로 실제 모델을 붙여볼 수 있습니다.
- 키가 없으면 **모의 모델**이 같은 코드 경로로 스트리밍합니다. 설치도 키도 없이 전 기능이 돌아갑니다.
- 서버는 SSE를 순수 텍스트 스트림으로 변환해 내려보내므로 클라이언트는 프로바이더 차이를 모릅니다.

### 시스템 프롬프트는 서버에서만 조립한다

캐릭터의 페르소나는 비공개 설정입니다. 초기 구현은 클라이언트가 프롬프트를 조립했는데,
그러면 페르소나가 번들과 HTML에 실립니다. 지금은 클라이언트가 `roomId`와 새 발화만 보내고
서버가 대화 기록을 읽어 프롬프트를 만듭니다 — **페르소나가 브라우저에 도달하지 않습니다.**

### 차트를 직접 그렸다

Recharts 같은 라이브러리 대신 SVG를 직접 그렸습니다. 데이터 시각화에서 신경 쓰고 싶었던 것들이
라이브러리 기본값과 어긋나서입니다.

- 색만으로 정보를 전달하지 않습니다 — 증감은 ▲▼ 아이콘과 텍스트를 함께 씁니다.
- 모델 색을 고정 매핑해 어떤 차트·표에서도 같은 모델이 같은 색입니다.
- **모든 차트에 "표 보기" 전환**이 있습니다. 툴팁 없이도 모든 값에 도달할 수 있어야 합니다.
- 크로스헤어는 포인터에 스냅하고 ←/→ 키보드로도 탐색됩니다.

### 실사용 지표를 시드 지표와 "합쳐서" 보여준다

데모라 지표가 비어 있으면 화면이 죽고, 전부 가짜면 서버화한 의미가 없습니다.
그래서 시드 90일 뒤에 **실제 사용(usage_events·실가입)을 이어 붙입니다.**

다만 **섞지 않는 선**을 그었습니다. 유저가 연결한 외부 모델(BYOK)의 토큰을 자사 모델(koji/luca)
원가에 매핑하면 데이터가 거짓이 됩니다. 그래서 DAU·신규·턴·토큰 **총량**만 합산하고,
모델별 분해·GPU 비용·마진은 시드 전용으로 두고 화면에 그렇게 밝혔습니다.
실사용 토큰은 주간 스택에서 별도의 회색 세그먼트로 나타납니다.

### 서버리스에서 "중단"이 다르게 동작한다는 걸 배포하고 알았다

로컬에서는 클라이언트가 연결을 끊으면 응답 스트림이 취소되고, 서버가 받은 데까지를
`interrupted=true`로 저장합니다. **Vercel에서는 연결 종료가 실행 중인 함수에 전파되지 않아**
함수가 스트림을 끝까지 돌려 전체 응답을 저장했습니다. 화면은 "중단됐어요"인데
새로고침하면 전체 응답이 나오는 버그였고, 배포 URL로 E2E를 돌려서 잡았습니다.

지금은 클라이언트가 `POST /api/rooms/[id]/interrupt`로 "여기까지 받았다"를 명시적으로 알립니다.
원래 요청의 저장이 먼저 끝났든 나중이든 최종 상태가 같도록, 늦게 도착한 저장은
채번 자리(`expectedSeq`)가 어긋나면 스스로 물러납니다.

### 테스트를 기능과 같은 커밋에 넣었다

"나중에 테스트" 대신 티켓마다 테스트를 완료 조건에 넣었습니다. 현재 **유닛·통합 197개 + E2E 9개**입니다.

- **라우트 핸들러를 `next/headers` 없이** 설계했습니다. 쿠키를 `Request`에서 직접 읽고 응답 객체에
  심어서, 통합 테스트가 dev 서버 없이 핸들러를 그대로 호출합니다.
- 통합 테스트는 진짜 Postgres(docker)에 붙습니다. 파일마다 truncate하고 직렬 실행합니다.
- E2E는 전용 DB를 매 실행 시드로 되돌리고 두 앱을 동시에 띄웁니다.
  `E2E_BASE_URL`을 주면 **같은 스위트가 배포 URL로 재실행**됩니다 — 위 중단 버그를 이렇게 잡았습니다.

### git — bare + worktree, 티켓당 브랜치 하나

`feature-*` 브랜치 하나가 티켓 하나이고, main 위로 rebase한 뒤 fast-forward로만 병합합니다
(`merge.ff=only`). 작업 문서는 [`docs/tasks/`](./docs/tasks/)에 티켓별로 있고,
각 문서 맨 아래 **"구현 결과"** 에 설계 대비 무엇을 왜 다르게 했는지 적어 뒀습니다.

## 로컬에서 실행하기

배포 URL로 충분하지만, 코드를 직접 돌려보실 경우입니다. Docker와 Node 20+, pnpm이 필요합니다.

```bash
cp .env.example .env      # 기본값이 docker-compose와 맞춰져 있어 그대로 쓰면 됩니다
docker compose up -d      # Postgres (호스트 5433)
pnpm install
pnpm db:migrate && pnpm db:seed
pnpm dev                  # web :3000 · office :3001
```

오피스 비밀번호는 `.env`의 `ADMIN_PASSWORD`(기본 `theta-office`)입니다.

```bash
pnpm test        # 유닛 + DB 통합 (docker 필요)
pnpm e2e         # Playwright — dev 서버와 시드를 자동으로 준비합니다
pnpm typecheck && pnpm build
```

### 환경 변수

| 키 | 필수 | 없으면 |
| --- | --- | --- |
| `DATABASE_URL` | ✅ | 앱이 뜨지 않습니다. 기본값은 docker-compose와 동일 |
| `TEST_DATABASE_URL` | 테스트만 | `pnpm test`가 실행되지 않습니다 |
| `SESSION_SECRET` | ✅ | 세션 쿠키와 오피스 토큰에 서명할 수 없습니다 |
| `ADMIN_PASSWORD` | ✅ | 오피스에 아무도 들어갈 수 없습니다 |
| `GOOGLE_CLIENT_ID` / `_SECRET` | — | **"Google로 계속하기" 버튼이 자동으로 숨겨집니다.** 나머지는 정상 |

Google 로그인을 켜시려면 [`docs/setup-google-oauth.md`](./docs/setup-google-oauth.md)에
콘솔 클릭 순서까지 적어 뒀습니다.

```
apps/
  web/          유저 앱 — 페이지 10개 + 채팅 스트리밍 프록시
  office/       운영 오피스 — 페이지 5개 + 자체 SVG 차트 킷
```

## 한계 — 실서비스라면 다음에 할 것

포트폴리오 범위에서 의도적으로 접어 둔 부분입니다.

- **이미지 저장이 DB(bytea)입니다.** `ImageStore` 인터페이스 뒤에 있어 교체 지점은 분리돼 있지만,
  실서비스라면 오브젝트 스토리지 + CDN입니다. 업로드 검수·신고도 없습니다.
- **플롯 수정 화면이 없습니다.** 만들기와 삭제만 됩니다.
- **토큰은 글자 수 기반 추정치입니다.** 프로바이더가 usage를 안 주는 경우가 많고 모의 모드는
  애초에 값이 없어서입니다. 화면에 "추정" 라벨을 붙였습니다.
- **중단해도 업스트림 생성은 끝까지 진행됩니다**(서버리스 한정). 연결 종료가 함수에 전파되지 않아
  이미 시작된 토큰 소비를 막을 수 없습니다. 자체 호스팅에서는 멈춥니다.
- **연결되지 않은 업로드 이미지가 남습니다.** 실서비스라면 만료 정리가 필요합니다.
- 매출·GPU 비용·A/B 실험은 시드 데이터입니다. 대응하는 실데이터가 없습니다.
